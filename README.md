# TriAL Central de Compras — Downloads

Instalador da **TriAL Central de Compras** (TriAL Smart Softwares).

Este repositório guarda **só os arquivos de instalação** — não há código-fonte aqui.

## Baixar

- **Instalador mais recente (Oracle, Windows Server 64 bits):**
  [TriAL-Central-de-Compras-Instalador-Oracle.zip](https://github.com/TriALSmart/central-de-compras-downloads/releases/latest/download/TriAL-Central-de-Compras-Instalador-Oracle.zip)
- Todas as versões, com o **SHA-256** de cada arquivo (`SHA256SUMS.txt`): [Releases](https://github.com/TriALSmart/central-de-compras-downloads/releases)

Requisitos e passo a passo da instalação: <https://trialsmart.com.br/central-de-compras.html>

A instalação pede o **token de licença** enviado pela TriAL. Depois de instalada, a aplicação se atualiza sozinha, em um clique — não é preciso voltar aqui.
